A policy-gated execution layer for Binance AI Agents. AgentGuard checks the intent before a tool call, independently verifies the result after execution, and fails closed when reality does not match policy.

One execution path, three safe outcomes

Agent intent→Policy gate→User confirmation→Binance Spot→Independent verifier→Receipt + hash
VERIFIED

Safe result released

Order filled, identity bound, notional within budget, and slippage within policy.

BLOCKED

Stopped before execution

Intent exceeds policy. No Binance order is submitted and the receipt explains why.

FROZEN

Failed closed

Execution returned an unsafe result. The task is isolated and cannot continue.

Reproduce in under five minutes

npm install
npm run demo
npm run judge:check

The simulator is deterministic and never moves funds. The public receipt contains no API key, secret, passphrase, or session credential.

Optional live MCP read

One command

npm run live:run -- --read-only

Uses the local Codex CLI's approved Binance MCP OAuth session. No credential is copied into this repository.

Fail-closed boundary

The default path only reads the Agentic Spot account and a fresh BNBUSDT quote. The bridge rejects Binance write tools unless a separate write allow-list and explicit confirmation are both present.
