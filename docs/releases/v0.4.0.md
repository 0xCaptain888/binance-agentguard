# AgentGuard v0.4.0

## BSC owner-custodied rebalancing preview

This release adds an isolated BSC rebalancing path without changing the
existing Binance CEX evidence or judge flow.

### Added

- two-asset `AgentGuardVault` with owner custody and bounded operator authority;
- USD action/daily budgets, oracle freshness, slippage, cooldown, nonce and
  allocation-improvement enforcement;
- independent RPC verification with snapshot, calldata, event and transfer
  binding; execution and snapshot block hashes are rechecked after historical
  reads, transaction/receipt/log metadata must agree, and confirmations use
  an uncached final chain head;
- persistent proof journal, wallet challenge sessions and incident recovery;
- local Anvil demo with real contract bytecode execution and mock assets;
- keyless unsigned BSC testnet deployment preparation and owner-wallet console;
- independent deployment attestation of exact creation calldata, runtime,
  immutable configuration and initial policy, with two-confirmation and reorg
  checks; uncertain wallet submission prevents automatic duplicate deployment;
- responsive execution console with first-viewport wallet and pause controls;
- redacted offline configuration doctor and dual-RPC read-only deployment
  preflight covering recent blocks, dependency code, oracle freshness,
  two-way route quotes, owner test gas and buffered constructor gas estimates;
- deployment readiness expires after 60 seconds and is checked again before
  requesting wallet confirmation; failed checks keep deployment disabled;
- rebalance submission recovery that saves public metadata before the wallet
  request, prevents concurrent sends with Web Locks, restores the original plan
  after reload and only clears matching verified receipts; expired/consumed
  plans can release the marker without claiming verification;
- final verification RPC interruptions keep the saved job in `VERIFYING` for
  retry against the same transaction; receipts persist block anchors and the
  observed confirmation count in the proof journal;
- local trade/fault execution journals the returned hash before confirmation
  reads; retries reuse that hash and concurrent execution requests share one
  broadcast; the journal exposes a local retry control even without live pricing;
- local trade gas estimates include 20% headroom for timestamp-dependent storage
  costs; a regression covers a timestamp advance between estimation and mining;
- wallet login invalidation during account/signature/session prompts, listener
  cleanup, 15-minute expiry and HTTP 401 recovery; transaction preparation stays
  bound to its original session and late responses cannot revive an older login;
- a wallet switch during an open rebalance transaction dialog retains the
  returned hash for recovery without a second send or automatic verification;
- 75 BSC contract/service/configuration/deployment/submission/wallet-session/operations tests in addition to the original nine;
- explicit HTTPS origin and strict Host/Origin validation for public testnet
  gateways; forwarded headers cannot override the trusted origin;
- pending-transaction reconciliation without signing or rebroadcasting,
  redacted operations/readiness endpoints, RPC failure recovery and mismatch
  freezing; a process lock prevents concurrent journal writers;
- non-root Docker image and HTTPS gateway configuration with persistent journal
  volume, backed by an operations guide for restart, backups and incident alerts;
- Local resets refresh both mock oracles on-chain so long-running and repeated drills retain fresh test prices;
- oracle-outage status that hides valuation while retaining anchored balances
  and owner exit controls, including on a fresh page load;
- local oracle-failure drill and fourteen desktop/mobile/deployment/recovery/session
  Chromium cases, all passed in Linux CI on October 24, 2026; the wallet/RPC-stub
  cases do not establish real BSC deployment or wallet interoperability;
- 84/84 Node tests passed on Node 20.18 and 22, public-testnet Docker image built,
  and CodeQL completed successfully; local macOS browser execution remains
  blocked by the sandbox;
- verification run: https://github.com/0xCaptain888/binance-agentguard/actions/runs/40091435120.

### Boundaries

- unaudited, BSC testnet only, standard ERC-20 assets only;
- no public deployment, ERC-8004 registration or marketplace listing included;
- local receipts are not public-chain or Set and Earn campaign evidence;
- local fixtures stay loopback-only; public testnet hosting requires explicit
  operator configuration and is not provisioned by a container build;
- the testnet gateway and monitor do not constitute an audited production system.
